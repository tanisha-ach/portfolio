## About This Portfolio

I'm a UX designer with 6+ years of enterprise experience (IBM, Lowe's, Mondelez, AMEX, GSK). This repository documents a new practice: using AI coding tools to move from Figma prototype to deployed interface — collapsing the traditional design-to-engineering handoff into a single workflow.

**My process for every project:**

```
Brief  →  Research  →  Figma  →  Design prompt  →  Claude Code  →  Deployed
```

Each project here began with a real design problem, was prototyped in Figma, then built into a live, production-grade interface using Claude Code or a similar AI tool. Nothing here is a template — every design decision is intentional and documented.

### 01 · SightLine AI — Hero Section
`HTML · CSS · Vanilla JS · Claude Code`

**Brief:** Design a hero section for an AI home inspection startup — computer vision that analyzes crawlspace, roof, and foundation images and auto-generates standardized reports.

**Design direction:** Retro-futurist meets mid-century modern. 80s synthwave energy on a warm beige ground — terracotta, neon cyan, Space Mono, and Josefin Sans. Halftone dot texture, CRT scanlines, and gold corner brackets.

**Features built:**
- Animated scan beam sweeping across a real house photograph
- Magenta defect-detection ping markers firing as the beam passes each zone (roof, wall, foundation)
- Typewriter-reveal defect badges (`RIDGE MOISTURE`, `SIDING GAP`, `FOUNDATION CRACK`)
- LED status widget cycling through inspection phases
- Fully responsive two-column layout

## Design Philosophy

I write detailed design briefs before touching any tool — defining aesthetic direction, color system, typography, motion language, and copy. The brief becomes the prompt. Claude Code implements it. I review against the original intent and iterate.

The result is interfaces that have a genuine point of view — not AI-generated defaults, but deliberate design executed through AI.
